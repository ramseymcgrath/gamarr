# Gamarr v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Dockerized Arr-style game catalog that searches IGDB by platform, searches Newznab indexers, sends selected NZBs to SABnzbd, and retains a reconciled download library.

**Architecture:** A Next.js modular monolith serves the React UI and route handlers. Domain services depend on narrow IGDB, Newznab, and SABnzbd ports; Drizzle repositories persist normalized settings, games, platforms, library entries, and download attempts in SQLite.

**Tech Stack:** TypeScript, Next.js 16, React 19, Node.js 24, stable Drizzle ORM with `better-sqlite3`, Zod, TanStack Query, React Hook Form, Tailwind CSS, shadcn/ui primitives, `igdb-api-node`, `fast-xml-parser`, Vitest, React Testing Library, MSW, Playwright, Docker.

## Global Constraints

- Run as one non-root Docker container listening on port 3000.
- Persist all mutable data beneath `/config`; SQLite is `/config/gamarr.db`.
- Support IGDB, multiple Newznab indexers, and one SABnzbd server in v1.
- Support every IGDB platform with visibility, search-alias, and category controls.
- Do not add monitoring, quality profiles, Torznab, torrents, imports, renames, filesystem scans, or application login.
- Require explicit platform selection before release search.
- Never return saved secrets to the browser or emit them in logs.
- Require `GAMARR_ALLOWED_ORIGINS` as an exact scheme/host/port allowlist and reject unknown hosts before routing.
- Keep browser release DTOs opaque; provider URLs and credentials remain server-side.
- Use tests before production code and verify the expected RED failure.
- Use maintained libraries for framework, validation, queries, XML, forms, and testing; keep vendor adapters narrow when no suitable maintained SDK exists.
- Preserve partial indexer successes and explain match ranking.
- Do not automatically retry an ambiguous SABnzbd submission.
- Meet WCAG 2.2 AA, including keyboard-only use, 320px reflow, reduced motion, and non-color status labels.
